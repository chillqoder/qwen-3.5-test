# Flappy Bird Clone

Браузерная игра в стиле Flappy Bird на чистом JavaScript.

## Запуск

Просто откройте `index.html` в браузере.

## Управление

- **Пробел** — взмахнуть крыльями
- **Клик мыши** — взмахнуть крыльями
- **Касание экрана** — взмахнуть крыльями (мобильные)

## Особенности

- Плавная физика на основе deltaTime
- Адаптивный дизайн (десктоп + мобильные)
- Сохранение рекорда в localStorage
- Интерфейс на русском языке

## Структура проекта

```
flappy-bird-clone/
├── index.html          # Точка входа
├── css/
│   └── styles.css      # Стили
├── js/
│   ├── config.js       # Константы игры
│   ├── input.js        # Обработка ввода

│   ├── pipes.js        # Генерация труб

│   ├── game.js         # Игровой цикл
│   └── main.js         # Инициализация

    └── fonts/
```
